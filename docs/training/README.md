# Training materials

For whoever trains the Assembly's staff. Two courses, built on the [user guide](../user/README.md):

| Course | For | Length |
|---|---|---|
| [Planners and administrators](planners.md) | Physical planners, district administrators | 2 days |
| [Field officers](field-officers.md) | Staff who capture data on phones | half a day, half of it outdoors |

Use the [trainer's checklist](trainer-checklist.md) the day before.

Each exercise says what the trainee should end up with, so they (and you) can tell whether it worked. Exercises use the practice files in `fixtures/generated/` (made with `make fixtures`): a small invented community with parcels, buildings, streets, a drain, a flood-prone area and a drone image. Nothing in them is real.

Print the [user manual](../manual/user-manual.html) for each trainee, or have it open on their screen.
