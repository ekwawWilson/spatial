# System administration

*For system administrators.*

## Regions and districts
**Regions & districts** lists every Assembly (MMDA). Add regions first, then districts. A district can be deactivated, which hides it from its members, but never deleted, so its history is kept.

## Users
**Users** lists every account.
- **Create and invite:** creates an account and emails a link to set a password. To give someone access to a district, add them from that district's **Members** page (you can open any district as system administrator).
- **Unlock** clears a sign-in lock after too many wrong passwords.
- **Send password reset** emails a fresh link.
- **Deactivate** stops someone from signing in, without deleting their history.
- **System admin** gives full access to every district. You can't remove your own system admin rights or deactivate yourself.
